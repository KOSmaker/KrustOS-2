# KrustOS-2
Double boot private OS.
-----------------------
## Features:
> 1.You can choose from what kernel to load in.

>2.combined file system, you can acess files from both booted options.

>3.open project, You can change it for yourself!
----------------------
## What kernel?
>the 1.st boot option is running on modified KrustKernel that is KrustOS concept.

>the 2.st boot option is running on Arch linux kernel, so you can browse internet, and do things online, also you can modify all what you want!
---------------------
## Why KrustKernel is safe?
>The KrustKernel does not have acess to internet, bluetooth, and USB-ports, so it is basicly imposible to connect to!
--------------------
## Modifications
>You're welcome to modify KrustKernel files, and make plugins to make it more compatible with other devices, and user-friendly!
